B. STRUKTUR BAHASA ID + EN
===========================
Di src/data/portfolio.ts terdapat:

contentByLocale = {
  id: { ... },
  en: { ... }
}

Bagian "id" adalah Bahasa Indonesia.
Bagian "en" adalah English.

Default bahasa diatur di:

languageConfig = {
  defaultLocale: "id",
  ...
}

Jangan ubah "id" menjadi "en" jika Anda ingin website pertama kali terbuka dalam Bahasa Indonesia.

Pilihan bahasa visitor disimpan di browser dengan localStorage. Jadi visitor yang pernah memilih EN akan tetap menggunakan EN ketika kembali dengan browser yang sama. Untuk visitor baru, default tetap ID.

1. Background Three.js di section setelah hero
----------------------------------------------
Konfigurasi utama:

ambient3D: {
  enabled: true,
  particleCountDesktop: 460,
  particleCountMobile: 170,
  maxPixelRatio: 1.35,
  maxOpacity: 0.34,
  rotationSpeed: 0.00115,
  orbOpacity: 0.24,
  ringOpacity: 0.18,
  particlesOpacity: 0.32,
}

REKOMENDASI LEBIH LEMBUT:

ambient3D: {
  enabled: true,
  particleCountDesktop: 320,
  particleCountMobile: 110,
  maxPixelRatio: 1.20,
  maxOpacity: 0.22,
  rotationSpeed: 0.00075,
  orbOpacity: 0.14,
  ringOpacity: 0.10,
  particlesOpacity: 0.18,
}

Arti konfigurasi:
- maxOpacity
  Semakin kecil, seluruh background 3D semakin samar.

- orbOpacity
  Mengatur transparansi bola/wireframe utama.

- ringOpacity
  Mengatur transparansi garis orbit.

- particlesOpacity
  Mengatur transparansi partikel.

- rotationSpeed
  Mengatur kecepatan gerak. Semakin kecil = semakin tenang/elegan.

- particleCountDesktop
  Jumlah partikel pada laptop/desktop.

- particleCountMobile
  Jumlah partikel pada HP.

- maxPixelRatio
  Semakin kecil akan semakin ringan untuk GPU/performa browser.

Jika ingin background Three.js dimatikan:

enabled: false


2. Three.js pada hero
---------------------
Cari hero3D:

hero3D: {
  enabled: true,
  particleCountDesktop: 1100,
  particleCountMobile: 360,
  maxPixelRatio: 1.6,
  rotationSpeed: 0.0016,
  pointerStrength: 0.38,
  geometryDetail: 2,
  orbOpacity: 0.42,
  ringOpacity: 0.32,
  particlesOpacity: 0.62,
  satelliteCount: 7,
  clickPulse: 0.22,
}

REKOMENDASI HERO LEBIH LEMBUT:

hero3D: {
  enabled: true,
  particleCountDesktop: 800,
  particleCountMobile: 250,
  maxPixelRatio: 1.4,
  rotationSpeed: 0.0011,
  pointerStrength: 0.25,
  geometryDetail: 2,
  orbOpacity: 0.32,
  ringOpacity: 0.22,
  particlesOpacity: 0.42,
  satelliteCount: 5,
  clickPulse: 0.14,
}

pointerStrength:
Semakin kecil = gerakan mengikuti mouse semakin lembut.

clickPulse:
Semakin kecil = efek ketika visual diklik/tap semakin halus.

satelliteCount:
Jumlah node/titik yang mengorbit.
