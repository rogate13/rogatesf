# Rogate Sola Fide — Interactive Portfolio V8

One-page portfolio built with Next.js, TypeScript, Tailwind CSS, and Three.js.

## V8 updates

- Bilingual: Bahasa Indonesia (ID) + English (EN)
- Default language: Bahasa Indonesia
- Language switcher with ID/EN flag icons
- Language preference is saved in the browser
- All important visible UI copy is localized
- Existing theme switcher and Three.js visuals remain available
- Added `TUTORIAL_EDIT_DAN_KONFIGURASI.txt` for content, language, theme, and Three.js editing

## Main editable data file

`src/data/portfolio.ts`

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```
